# isaac_sim_2025

このプロジェクトは、NVIDIA Isaac Sim 2025を使用したシミュレーションプロジェクトです。

## 概要

Isaac Simは、NVIDIAの強力なロボティクスシミュレーションプラットフォームです。このプロジェクトでは、2025年版のIsaac Simを活用して、さまざまなシミュレーションタスクを実装しています。

## フォルダ構造

- `data/`: シミュレーションデータとアセット
  - `assets/`: 3Dモデルやテクスチャなどのアセット
  - `environments/`: シミュレーション環境の設定
- `docs/`: ドキュメント
- `extension/`: カスタム拡張機能
- `scripts/`: Pythonスクリプト

## セットアップ

1. NVIDIA Isaac Sim 2025をインストールしてください。
2. このリポジトリをクローンします。
3. 必要な依存関係をインストールします。

## 使用方法

詳細な使用方法は、`docs/IsaacSimプロジェクトの運用の仕方.txt`を参照してください。
